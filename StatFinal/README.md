# DockerFile and Jupyter Notebook Environment For Final Project

**Description**: How to pull down the files and create a docker image and notebook environment for our project.

## Quick start guide

1.  Download folder containing all files in this repository.
2.  Store the files in a local directory of your choosing.
3.  In a terminal window, navigate to the local directory containing `StatFinal`.
4.  Run the command `docker build`. The Docker image will be created on your system.
5.  To create the container, run the command `docker run` while still in the directory.
6.  Navigate to the docker container's terminal and run the container.
7.  In a web browser window, copy and paste the custom URL provided in the terminal window to access the Jupyter notebook environment to interact with the Analysis and code.
